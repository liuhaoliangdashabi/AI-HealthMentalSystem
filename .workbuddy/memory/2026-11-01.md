### 今日踩坑（重要，下次直接查这里）
- **`SERVER__PORT=55416` 劫持端口**：AI 终端环境里有 `SERVER__PORT`/`SERVER__HOST`，Spring 宽松绑定覆盖 `server.port`。命令行启动必须 `env -u SERVER__PORT -u SERVER__HOST java -jar ... --server.port=xxxx`。IDEA 启动不受影响。
- **common 传递 `spring-boot-starter-security`**：默认链要求所有请求 Basic 认证，连登录都 401。`exclude UserDetailsServiceAutoConfiguration` 无效，必须写 `SecurityFilterChain` 全放行（已建 `user-service/config/SecurityConfig`）。
- **StringRedisTemplate 读位图会坏**：`opsForValue().get()` 按 UTF-8 解码，位图字节还原不回来 → `days` 恒空。要用 `redis.execute` 拿 `byte[]`；且 `bits[i/8]` 要判长度防越界。
- **IDEA mmap 锁文件**：写 `DiaryService.java` 报「请求的操作无法在使用用户映射区域打开的文件上执行」，不是只读也不是占用，就是 mmap。规避：另建类，别改那个文件。
- **改了 yml 要重新 package 该模块**：网关加了 activity 路由但没重打包，请求仍打到 8050 报 B0120。`compile` 不会更新 fat jar 里的 `BOOT-INF/classes/application.yml`。
