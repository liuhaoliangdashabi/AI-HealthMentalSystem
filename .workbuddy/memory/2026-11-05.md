**补的三处缓存**（都是读多写少、key 有限、能忍延迟）
1. knowledge `ArticleService.getHotArticle()` → `cacheName=articleHot`，TTL 60s；create/改状态/改文/删文/改分类全部清
2. diary `ActivityService.listRecentActivity()` → `cacheName=activity`，TTL 10min；增删改日记清
3. analytics `AnalyticsService.getUVTrend()` → 复用 `analytics`，TTL 60s（一次请求 30 次 HLL）

**故意不缓存**：分页列表（key 爆炸）、咨询消息（实时性）、`selectCount(null)` 全表 count（缓存也救不了）。

**缓存返回类型铁律**：`@Cacheable` 方法绝不能返回 `List.of()` / `stream().toList()`。
JDK 不可变集合写进 JSON 会带 `java.util.ImmutableCollections$ListN`，读回来反序列化直接炸。
统一 `Collectors.toCollection(ArrayList::new)` 或 `new ArrayList<>()`。
