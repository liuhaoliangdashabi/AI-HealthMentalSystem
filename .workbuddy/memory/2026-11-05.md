**看板全 0 事故（13:57 定位，最高价值坑）**
- 现象：重启后看板 totalDiaries=0、totalSessions=0、avgMoodScore=7.0（前端兜底），总用户数 12 正常，30 天活跃 4 正常
- 根因：`@Value("${internal.diary-service.url: http://127.0.0.1:8030}")` **冒号后多了一个空格**，Spring 把空格算进默认值 → baseUrl 变成 `" http://127.0.0.1:8030"` → `URI.create` 抛 `IllegalArgumentException: Illegal character in scheme name at index 0`（已用 jshell 实测）→ client catch 吞异常返回 `empty()` → 数字全 0 且不报错
- `UserStatClient` 无空格，所以只有它就是好的——这是最好用的对照
- 修复：两个 client 默认值去掉空格；已重新 compile 通过
- **教训：`${key:default}` 冒号后绝不能有空格；兜底 catch 会把配置错误伪装成"没有数据"**
