### 关键坑（今天最大的坑）
`application.yml` 末尾的 `internal.*.url` 覆盖了 `@Value` 默认值：
```yaml
internal:
  diary-service: {url: http://127.0.0.1:8030}   # ← lb 把 127.0.0.1 当服务名 → No instances available for 127.0.0.1
```
必须写成服务名 `http://diary-service`。UserStatClient 因 key 少写 `.url`（`internal.user-service`）
反而读不到配置、用了默认值，**只有写错的那个能跑**。
教训：`@Value` 的默认值只在配置不存在时生效，yml 有 key 就完全没用，且无任何提示。
